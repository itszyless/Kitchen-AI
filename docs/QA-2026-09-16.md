# Onboarding, accounts and recipe categories: validation

## Automated checks

- TypeScript and ESLint pass; 90 unit tests pass across 12 files.
- Expo web export passes; the browser walkthrough reports no console errors.

- Embedded PostgreSQL tests for username uniqueness, auth metadata enforcement, ownership, private email resolution and login rate limits.

- Recipe tests cover overlapping labels, combined filters, saved filters, unknown durations and exactly 20-minute recipes.

## Browser walkthrough

Tested the local Expo web preview at a 390 × 844 viewport:

- Welcome mockup on white, full clickable sign-in sentence, and existing-account form with Back.

- All onboarding questions initially unselected; Continue disabled until an explicit answer.

- Deselecting the last diet or allergy item disables Continue. No food allergies is an explicit choice card.

- Birthday choice, household groups, country and acquisition choices.

- Summary with one Let’s go action, final registration form and Back to the retained summary.

## Hosted backend checks

The username migration was applied and recorded in the Supabase migration history. The username-login Edge Function was deployed with its own password authentication. Invalid username availability returns false; an unknown username/password returns a generic 401 response without revealing email addresses.

## Limits

A successful real-account registration/sign-in and Google OAuth round trip were not exercised in this walkthrough. Google provider configuration and real iOS/Android testing remain outstanding. Apple sign-in and the proposed post-registration paywall remain deferred.

With unrestricted food preferences, nine recipes currently qualify for Under 20 min: one original recipe and eight imports with source-verified total times. Most imported recipes have unknown total durations and are intentionally excluded from that filter.
